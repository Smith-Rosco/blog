# 安装并配置Git

{% note info flat %}

打开[官方地址](https://git-scm.com/downloads)下载安装包,一路下一步.安装完成

{% endnote %}



## 将Git与你的Gitee账号绑定

1. 鼠标在任何位置右键打开Git Blash

2. 执行下列代码以绑定用户

``` markdown
git config --global user.name "你的Gitee用户名"
```

继续执行下列代码以绑定邮箱

``` markdown
git config --global user.email "你的Gitee注册邮箱”
```



## 生成SSH密钥

1. 在Git Blash中执行以下代码以生成SSH密钥

``` markdown
ssh-keygen -t rsa
```

2. 打开SSH密钥所在目录

``` mark
`C:\Users\你当前的用户名\.ssh`
```

3. 打开文件：id_rsa.pub，复制



## 配置SSH密钥

1. 打开gitee主页，点击右上角头像，点击设置或者账号设置

2. 在安全设置中选择SSH公钥

3. 粘贴公钥到相应位置，确定

# 安装hexo

{% note info flat %}

hexo 需要 ` node.js `环境才能安装，所以先安装 node.js

进入 node.js [官方地址](https://nodejs.org/en)下载安装包，一路下一步

{% endnote %}

执行以下代码并返回版本号,如下图所示，即为正确安装

``` markdown
node -v
v18.16.0
```



##  部署hexo环境

1. 创建一个名为blog的文件，在文件里打开Git Bash,执行下列代码以初始化hexo

``` markdown
 hexo init
```

2. 继续执行以下代码以部署本地hexo网页

``` markdown
hexo s
```

3. 按住'Ctrl'的同时点击网址即可打开，或者复制到浏览器打开

``` markdown
http:localhost:4000
```

{% note warning flat %}

ps:如果打开网页错误，localhost拒绝访问，你可以试试直接在浏览器输入` 127.0.0.1：4000 `

{% endnote %}

{% note success flat %}

到此你应该能看到nexo的默认网页了

{% endnote %}

# 将blog上传到gitee

## 在gitee上新建一个仓库

1. 点击右上角加号-新建仓库，随便取个名称，选择开源（不然无法用 Gitee Pages 发布网页），点击创建
2. 进入创建好的仓库，点击服务` Gitee Pages `，然后发布网页
3. 你会在当前页面得到一个网址，它将是你以后访问博客的网址，复制这个网址

## 配置本地文件

1. 打开blog文件夹下的` _config.yml `，将复制的网址填入` url:   `后（":"后面有一个空格），并添加 root 信息

``` markdown
url: 你复制的网址
root: /你创建的仓库名
```

2. 返回 Gitee ，打开你的仓库，点开橙色按钮` 克隆/下载 `，复制 https 地址
2. 继续编辑 _config.yml 文件，滑到最后找到` deploy `修改为下列代码

``` markdown
deploy:
  type: git
  repository: 你复制的https地址
  branch: main
```

4. 安装 hexo-deployer-git 自动部署发布工具，在 Gitee Blash 中执行

``` markdown
npm install hexo-deployer-git --save
```

5. 生成页面

``` markdown
hexo g
```

6. 上传文件

``` markdown
hexo d
```

{% note success flat %}
此时放回你的Gitee仓库，你应该会看到内容更新

在浏览器中执行之前复制的网址，就可以访问你的网页了

{% endnote %}

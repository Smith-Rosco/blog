# 建议 & 注意事项

{% note warning flat %}
安装完后的网页与作者的网页不同，这是因为很多功能是默认关闭的

详细配置在 

- Butterfly 安装文档(三) 主题配置 -1 
-  Butterfly 安装文档(四) 主题配置 -2 

{% endnote %}

## 修改配置的正确姿势

- 用 Vscode 打开配置文件` _config.ym ` 和 ` _config.yml `并打开` 文件->自动保存 `
- 在你的博客文件夹下打开 Git Blash，依次输入以下代码

``` markdown
hexo clean
hexo g
hexo s
```

- 打开[localhot:4000](http://localhost:4000/blog/ )

做完上述步骤后，你可以实现修改配置的同时，网页自动刷新并呈现出相应的效果

{% note warning %}

{% endnote %}

## 修改配置文件` _config.yml  ` 或 ` _config.yml `后生成网页报错

对任何配置文件的修改都需要在冒号':'+ 空格 ` blankspace' 后面，一定不要忘了空格！！！
